A letterpress design system for apps and articles. Cool rag paper, blue‑black ink, twelve gemstone accents, hairline rules. Print has relief: a pressed button is debossed into the sheet, the badge is a seal affixed a hair proud of it, a menu is a loose sheet laid on top — everything else stays flat.

Everything the system draws is layout‑free. The .cl-* caller layer owns every margin, grid and measure on this page — proving the one rule: a component never carries its demo's spacing with it.

Components

Each is a sealed box in an isolation frame. The frame and its padding are caller chrome; the component brings only itself.

.press-button — a typeset button

default · -accent · -ghost · -danger · -icon · -small · -large · aria-pressed · disabledhover is a wash, press a deboss

A small-caps label set in a hairline frame, square in the line. Hover lays a 5% ink wash over the ground; press is a deboss — the sheet pushed in, a hard 1px inset on the upper-left — and nothing moves. aria-pressed="true" holds the deboss with the accent tint. The last button is aria-disabled, the app default: styled spent but still focusable and hoverable (tab to it).
